CuidadoPet — Política de Privacidade

Última atualização: abril de 2026

1. Sobre o aplicativo

O CuidadoPet é um aplicativo de organização de cuidados com animais de estimação domésticos. O app é local — todos os dados são armazenados exclusivamente no dispositivo do usuário. Não há servidores, contas de usuário ou sincronização na nuvem.

2. Dados coletados

O CuidadoPet não coleta nem transmite nenhum dado pessoal ou de saúde para servidores externos.

Os seguintes dados são criados e armazenados apenas localmente no dispositivo:

  • Nome, espécie, raça e peso dos pets cadastrados
  • Registros de medicamentos e horários de administração
  • Planos alimentares e registros de refeições
  • Registros de hidratação
  • Entradas do diário de saúde e histórico de peso
  • Foto do pet (salva no armazenamento interno do app)

3. Permissões do aplicativo

  • Notificações: para enviar lembretes de medicamentos e refeições
  • Alarmes exatos: para garantir que os lembretes sejam precisos
  • Câmera: para tirar foto do pet (opcional)
  • Acesso a imagens: para escolher foto da galeria (opcional)
  • Inicialização do sistema: para reconfigurar alarmes após reinicialização

4. Compartilhamento de dados

O app não compartilha dados com terceiros de forma automática.

O tutor pode optar por compartilhar relatórios manualmente (WhatsApp, e-mail, etc.) usando as funções de exportação. Esse compartilhamento é sempre iniciado pela ação explícita do usuário.

5. Aviso médico-veterinário

O CuidadoPet é uma ferramenta de organização pessoal e não substitui avaliação, diagnóstico ou prescrição veterinária. As informações registradas no app são observações do tutor e não devem ser usadas como base para decisões médicas sem orientação profissional.

6. Retenção e exclusão de dados

Todos os dados ficam no dispositivo. Para apagar os dados, o usuário pode desinstalar o aplicativo, o que remove todos os arquivos e o banco de dados local.

7. Menores de idade

O aplicativo não coleta dados de menores de idade. O uso é destinado a tutores adultos responsáveis pelos animais.
